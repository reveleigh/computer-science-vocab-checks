# Computer Science Vocab Checks

A growing collection of cloze (fill-in-the-blanks) vocabulary worksheets for OCR Computer Science — GCSE (J277) and A Level (H446). Designed for classroom display and A4 printing.

Follow along as these are developed throughout the school year, week by week. Each worksheet targets ten key vocabulary words from a topic, with interactive reveal controls and an answer key.

## Use the Prompt Yourself

The file `Prompt_Instructions.md` contains the full specification used to generate these worksheets. You can give it to any AI agent (ChatGPT, Claude, Gemini, etc.) to create your own custom vocabulary checks on any topic.

### Example prompts to try:

1. *"Make a vocab check about network topologies for Year 10 OCR Computer Science."*
2. *"Make a vocab check about SQL and databases for Year 12 OCR A Level."*
3. *"Make a vocab check about primary and secondary storage for Year 9."*
